# Squad Nova · Pitchs

Deux pitchs de 5 minutes, en HTML, prêts à être publiés avec GitHub Pages.

| Fichier | Contenu |
|---|---|
| `index.html` | Page d'accueil avec les liens vers les deux pitchs |
| `smarttraffic.html` | SmartTraffic AI — prédire les rues praticables à moto à Cotonou |
| `greentrack.html` | GreenTrack AI — prévoir la soif des plantes et arroser juste à temps |
| `smarttraffic.pdf`, `greentrack.pdf` | Versions PDF des slides |
| `index-en.html`, `smarttraffic-en.html`, `greentrack-en.html` | Versions anglaises (slides et notes d'orateur) |
| `smarttraffic-en.pdf`, `greentrack-en.pdf` | Versions PDF anglaises |

## Pendant la présentation

- `←` `→` (ou espace, ou clic) : changer de slide. Sur téléphone : glisser.
- `N` : afficher les notes d'orateur et le chrono (`T` le remet à zéro).
- `F` : plein écran.
- `L` (ou le bouton `EN` / `FR`) : passer en anglais / en français, en restant sur la même slide.
- `Ctrl+P` : exporter en PDF (format 16:9, une slide par page).
- L'adresse se termine par `#3` pour ouvrir directement la slide 3.

## Publier sur GitHub Pages

1. Crée un dépôt et mets ces fichiers à la racine.
2. Dans le dépôt : **Settings → Pages → Build and deployment**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`.
3. Le site sera en ligne à `https://<ton-compte>.github.io/<nom-du-depot>/`.

## À remplacer avant le pitch

- Les citations, prénoms et durées de Koffi et d'Afi sont provisoires : remplace-les par ceux de vraies personnes interrogées.
- Les emplacements « photo à venir » attendent une photo (avec l'accord de la personne).
- Si tu modifies un texte en français, pense à faire la même modification dans la version `-en.html`.
- Les chiffres de GreenTrack (116 plantes, 93 %, −60 %) viennent de données simulées.
